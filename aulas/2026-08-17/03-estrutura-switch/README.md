# Estrutura switch

Solicita um número de 1 a 5 e usa `switch` para tratar cada opção. O programa também pratica o laço `do while` e a leitura de dados com `std::cin`.

- `cpp/main.cpp`: antigo **Exemplo 04**, apresentado pelo professor.

Nesta aula não foi registrada uma versão Java deste exemplo.

## Compilação e execução

Execute os comandos **a partir da pasta com os codigos de suas respectivas linguagens**:

### C++

```bash
g++ main.cpp -o main.bin
./main.bin
```
