# Desenho de retângulo

Exercício que desenha no terminal o contorno de um retângulo com 40 colunas e 6 linhas. O programa pratica laços `for` aninhados, operadores lógicos e o operador ternário para decidir quando exibir um asterisco ou um espaço.

- `cpp/main.cpp`: **Exercício 02**, solicitado pelo professor.

## Compilação e execução

Execute os comandos a partir desta pasta:

### C++

```bash
g++ main.cpp -o main.bin
./main.bin
```

O arquivo `main.bin` é gerado nesta pasta, mantendo o artefato de compilação separado dos demais códigos-fonte do repositório.
