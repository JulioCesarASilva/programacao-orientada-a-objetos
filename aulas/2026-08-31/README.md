# Aula de 31/08/2026

Nesta aula, o professor apresentou o início de um sistema de cadastro de
animais em C++. O código registrado em sala serve como base para um exercício
que deve ser completado pelos alunos.

| Tópico | C++ | Java | Origem |

| [01 — Cadastro de animais](01-cadastro-de-animais/) | Sim | — | Código apresentado e exercício propostos pelo professor |

## Conceitos praticados

- modelagem de classes, atributos e métodos;
- encapsulamento com atributos privados, *getters* e *setters*;
- criação de construtores;
- uso de `enum` para representar categorias;
- separação entre declaração (`.hpp`) e implementação (`.cpp`);
- uso de `switch` para exibir a alimentação do animal;
- planejamento das operações de um sistema CRUD;
- armazenamento de objetos com `std::vector`.

O código apresentado implementa a classe `Animal`. A conclusão da classe de
cadastro e das operações do sistema ficou como atividade para os alunos.
